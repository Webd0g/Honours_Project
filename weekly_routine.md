# Weekly Routine — Honours Coursework + Project

This routine balances:
- Coursework (primary focus this semester)
- Honours project progress (steady weekly work)
- Supervisor meetings
- Major project deadlines
- Protected personal time on Sundays

It is designed to be realistic, sustainable, and compatible with a PhD‑level workload.

**Monday:** Coursework Class 1
